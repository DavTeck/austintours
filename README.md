# Austins Tour & Travel & Travel Agencies

A modern, fully responsive East African safari tourism website.

## Brand Message
**WE CREATE THRILLING MEMORIES THAT LAST FOR A LIFETIME**

## Focus
Specializing in Uganda’s national parks and East African safari experiences:
- Queen Elizabeth National Park
- Murchison Falls National Park
- Lake Mburo National Park
- Kidepo Valley National Park
- Bwindi Impenetrable Forest (Gorilla Trekking)
- Masai Mara & Serengeti extensions

## Features
- Homepage with cinematic hero, featured destinations, packages, gallery, testimonials
- Filterable Destinations page
- Experiences (boat cruises, game drives, gorilla treks)
- About Us, Travel Journal, Contact / Booking form
- Sticky navigation, dark mode, WhatsApp floating button
- Mobile-first responsive design
- All prices removed — inquiry-based bookings
